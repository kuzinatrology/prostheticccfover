# Оболочка голени для трансфеморального протеза

Шесть этапов, каждый — отдельный скрипт, каждый перезапускается сам по себе.
Промежуточные результаты лежат в `anatomic/work/`, рендеры и отчёты —
в `anatomic/renders/`. **Все параметры в одном файле: `anatomic/config.py`.**

```bash
.venv/bin/python -m anatomic.run_all          # всё подряд
.venv/bin/python -m anatomic.stage4_surface   # или по одному
```

| Этап | Скрипт | Вход | Выход |
|---|---|---|---|
| 1 | `stage1_prepare.py` | `data/Leg_Prosthetic.stl` | `work/stage1_prosthesis.stl`, `work/stage1.json` |
| 2 | `stage2_sections.py` | этап 1 | `work/stage2_prosthesis.stl` (начало координат на оси колена), таблица сечений |
| 3 | `stage3_profile.py` | MakeHuman + `data/ref_*.png` | `work/stage3_profile.npz` |
| 4 | `stage4_surface.py` | этапы 2 и 3 | `work/stage4_surface.stl` |
| 5 | `stage5_flexion.py` | этап 4 | `work/stage5_surface.stl`, глубина выреза |
| 6 | `stage6_shell.py` | этапы 4 и 5 | **`cover_anatomic.stl`** |

## Системы координат

- Этап 1 ставит z вдоль пилона, y вперёд (по носку стопы), ноль на верху пилона.
- Этап 2 переносит начало координат **на ось колена**: z вниз отрицательный,
  x вдоль оси колена, y вперёд. Дальше всё в этой системе.

## Что чем задаётся

- **Абсолютный размер** — протезом: каждое сечение раздувается ровно настолько,
  чтобы вместить сечение протеза плюс `CLEARANCE_MM`.
- **Форма сечения и пропорции по высоте** — базовой сеткой MakeHuman (CC0),
  только отношения, без абсолютных размеров.
- **Кромка** — гладкой периодической кривой через 6 контрольных точек
  (`config.rim_control`). Сетка строится так, что каждый столбец заканчивается
  точно на кривой, поэтому край не повторяет треугольники.

## Главные ручки в `config.py`

| Параметр | Что делает |
|---|---|
| `CLEARANCE_MM` | зазор между протезом и внутренней стенкой |
| `WALL_THICKNESS_MM` | толщина стенки |
| `COVER_SECTION_STEP`, `COVER_ROWS` | густота сечений и строк сетки |
| `COVER_FULLNESS` | общая полнота силуэта (икра) |
| `RIM_FRONT_DIP_MM`, `RIM_NOTCH_DEPTH_MM` | передний спуск и глубина заднего выреза |
| `ANATOMY_T_BOTTOM` | на какой высоте голени MakeHuman сидит низ оболочки |
| `BOTTOM_CLEARANCE_MM` | насколько низ выше адаптера стопы |
| `GIRTH_SMOOTH_MM`, `CENTRELINE_SMOOTH_MM` | сглаживание по высоте |
